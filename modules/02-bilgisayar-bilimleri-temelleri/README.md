# AG CYBER LAB — Modül 02: Bilgisayar Bilimleri Temelleri

LEARN • PRACTICE • SECURE

Bağımsız, çevrimdışı çalışabilen, başlangıç seviyesi sanal eğitim laboratuvarı (10 ders, 10 etkileşimli uygulama, 10 mini test, 20 soruluk genel değerlendirme).

```bash
npm install
npm run dev     # geliştirme sunucusu
npm run build   # üretim derlemesi (dist/index.html)
```

- Teknoloji: React + TypeScript + Tailwind CSS + Lucide React (Vite ile derlenir)
- Veritabanı, backend, API anahtarı veya harici servis yoktur.
- İlerleme `localStorage` anahtarı `agcyberlab.module02.computer-science-fundamentals.v1` altında saklanır.
- Yapı: `src/data` (ders içerikleri ve sınav), `src/labs` (10 uygulama), `src/pages`, `src/components`, `src/progress.tsx` (ilerleme), `src/utils/numberSystems.ts` (sayı sistemi dönüştürücü).
