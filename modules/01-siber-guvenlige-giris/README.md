# AG CYBER LAB — Module 01: Introduction to Cybersecurity

**LEARN • PRACTICE • SECURE**

This is an independent, locally runnable learning module in the AG CYBER LAB Beginner Tier.

## Run locally

Requirements: Node.js (LTS) and npm.

```bash
npm install
npm run dev
```

Open the local URL printed by the development server. To create a production build, run `npm run build`.
