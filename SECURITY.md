# Security Policy

## Scope

AG CYBER LAB Beginner is an educational project containing local applications, learning materials, and simulated cybersecurity exercises.

The labs are designed for educational purposes. Users must only perform security testing in environments they own or have explicit authorization to assess.

Unauthorized access, testing, or activity against third-party systems is strictly prohibited.

## Reporting a Vulnerability

If you discover a potential security vulnerability within this repository, please report it responsibly.

Do not publish exploit details, sensitive information, or proof-of-concept material in public issues.

Contact the project maintainer through the official AG CYBER LAB communication channel: **@agcyberlab**.

Include the following information in your report:

- Affected module and version.
- Steps required to reproduce the issue.
- Expected and observed behavior.
- Potential impact, if known.

Do not include passwords, authentication tokens, personal information, private keys, or third-party confidential data.

## Response

Security reports will be reviewed by the project maintainer as time and project capacity permit.

No fixed response-time or resolution SLA is currently offered.

Please allow reasonable time for review before sharing additional information publicly.
